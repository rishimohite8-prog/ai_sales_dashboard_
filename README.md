# 🤖 AI Sales Dashboard

An AI-powered data analytics dashboard built using Streamlit.

## Features
- Upload CSV sales data
- Automatic data cleaning
- Sales visualization
- AI-based sales forecasting
- Business insights generation

## How to Run
pip install streamlit pandas matplotlib scikit-learn numpy
streamlit run app.py

## Sample Data
Use sample_sales_data.csv
